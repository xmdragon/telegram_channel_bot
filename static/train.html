🎯 AI训练使用指南

1. 手动训练步骤

  1. 复制包含推广内容的完整消息
  2. 粘贴到"原始消息内容"框中
  3. 将需要过滤的尾部内容（如订阅链接、投稿信息等）粘贴到"推广尾部内容"框中
  4. 查看预览效果，确认过滤是否正确
  5. 点击"提交训练样本"保存
  6. 重复多次以增加训练效果（建议至少5-10个样本）

2. 自动应用

  • 提交训练样本后，AI会立即学习并应用
  • 训练后的模型会自动应用到新消息的过滤中
  • 结合规则过滤，提供双重保障

3. 常见推广格式示例

👌订阅频道：@channel_name
👌投稿爆料：@contact_user
👌海外交友：@dating_channel

📢 订阅新闻频道
📣 商务合作 @business
🔗 更多精彩 t.me/xxx

4. 注意事项

  • 训练数据会永久保存在数据库中
  • 每个频道的推广格式可能不同，需要分别训练
  • 训练样本越多，AI识别越准确
  • 可以随时查看和删除训练历史
